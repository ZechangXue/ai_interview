使用说明

面试前配置（推荐）
1. 先自行申请 API Key（推荐 OpenAI，效果最好）。
2. 在 Settings 中填入 API Key，模型保持默认 gpt-4.1-mini 即可。
3. 回答风格推荐 极简提醒（Concise），卡壳时可随时切到 可读答案。
4. 输出模式保持默认：流式渲染 + ASR 模式，体验最佳。
音频与设备设置
1. 音频来源推荐选 System Audio (System Default)，优先监听面试官声音，不受你自己说话影响。
2. 自我测试时可切换到 Microphone。
3. 建议在正式面试前完成一次设备调试，确保输入源和音量正常。
实际使用流程
1. 上传资料（JD / 简历 / 笔记）后，点击 根据资料自动优化。
2. 完成后点击 开始监听。
3. 面试中先读一句回答，再按关键词展开；卡壳时切换 可读答案模式 继续讲。
下一题自动关旧卡（可选）
在 设置 中可勾选 下一题自动关闭当前卡片并继续监听。开启后，识别到面试官的新一轮完整提问时，会自动收起当前提词卡并继续监听、应对新问题；仍可用 Space 手动关闭当前卡。关闭该选项则须先手动关上一张卡后再听下一题。
一键导出与复盘总结
面试结束后点击 一键导出，可将本次面试中已记录的问题与回答导出为 PDF 便于复盘，并包含模型生成的中文面试总结。
窗口与成本建议
1. 窗口透明度建议 60% - 90%，方便与面试官保持眼神交流。
2. 一场约 30 分钟面试，API 消耗通常约 0.3 美元（随模型与问答密度波动）。
3. 建议回答节奏：先结论、再方法、最后结果，表达更自然。

核心功能

实时提词卡
监听面试问题后快速给出一句可朗读回答与关键词。
可读答案模式
支持从一句回答无缝展开为 3-4 句自然表达。
JD / 简历 / 笔记上下文融合
基于岗位要求和你的经历生成更贴合的回答思路。
历史记忆与追问应对
可结合近期问答历史，对面试官追问进行自然衔接回答。
